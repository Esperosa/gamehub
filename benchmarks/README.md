# Benchmarks

This folder stores benchmark artifacts that are useful for performance/history tracking.

Current artifact:

- `sudoku_16x16_medium_10.pdf`
  - Batch-generated Sudoku print sample used during 16x16 generation performance investigation.
  - Contains 10 generated `16x16 medium` puzzles exported as PDF.
- `solver_claims_audit_2026-02-08.json`
  - Deterministic audit sample for solver/generator claims (Sudoku/KenKen/Nonogram).
  - Generated by `scripts/audit_solver_claims.py`.

Utility benchmark scripts:

- `scripts/benchmark_game2048_solver.py`
  - CLI tuning/benchmark runner for 2048 solver.
  - Supports repeatable seed ranges and `--weight key=value` overrides.
  - Example:
    - `python scripts/benchmark_game2048_solver.py --games 50 --depth 3 --chance-branch-limit 8 --weight empty_cells=2600 --weight monotonicity=1900 --output benchmarks/game2048_solver_benchmark_50.json`

If newer benchmark runs are added, include:

1. What was measured.
2. Input parameters (size, difficulty, count, seed range).
3. Runtime environment note (CPU/OS/Python).
